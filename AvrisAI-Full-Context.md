## 0. TL;DR — что нужно знать сразу

- **AvrisAI** — голосовая платформа медицинской документации для врачей Центральной Азии (рынок №1 — Таджикистан/СНГ). Врач говорит во время приёма → система транскрибирует и генерирует SOAP-документацию, предлагает диагнозы/обследования, ведёт лабораторию, ночной обход и ОРИТ. Продукт компании **Hyperion Labs**.
- **Живой статус:** прод на **theavris.ai**. С 2026-07-07 корень — **маркетинговый waitlist-лендинг**; само приложение врача переехало на **`theavris.ai/app`**; портал лаборатории — **`/lab`**.
- **Версия приложения:** v3.5. Бэкенд **реализован и зрелый** (FastAPI, auth+OTP, audit-log, PWA, ревокация refresh-токенов, CI 58 pytest).
- **Стек фиксирован:** STT = OpenAI Whisper (+ собственный таджикский STT — Hyperion STT), LLM = **Anthropic Claude Sonnet**. Фронт — **чистый HTML/CSS/JS без фреймворков и сборки**.
- **Фокус:** сейчас команда работает **только над Avris**.
- **Рабочий язык общения — русский.** В продакшен-UI **нет эмодзи** — только inline SVG.

## 2. Проблема и решение

**Проблема:** врачи в СНГ/развивающихся рынках ведут документацию вручную; до ~40–60% времени уходит на бумаги, а не на пациентов. Нет единой электронной истории, результаты анализов теряются, нет преемственности. Западные продукты (Abridge, Suki, Nuance DAX) — только английский, дорого, без поддержки таджикского и стандартов СНГ. Российские МИС — БД без AI и голоса.

**Решение:** голосовой AI-ассистент, который слушает приём, создаёт документацию, советует и (в перспективе) управляет оборудованием кабинета. Работает на русском/таджикском/английском, по цене, доступной региону.

## 3. Продукт — что уже работает (веб-платформа v3.5)

**Аутентификация врача:** регистрация → email-верификация (6-значный OTP через Resend) → логин (JWT) → заполнение профиля → **одобрение администратором** → доступ. OAuth **Google** и **Mail.ru** (Apple — placeholder).

**Экраны приложения (SPA):**
- **Дашборд** — список пациентов сразу; 3 плоские карточки (пациентов сегодня / критические / SOAP за сутки), поиск+фильтры, FAB «Новый осмотр».
- **Осмотр (Consultation)** — 3 вкладки: *Осмотр* (55/45 сплит: запись слева, 4 SOAP-textarea справа; waveform, таймер, STT-язык RU/TJ/EN независим от UI), *Анализы* (результаты + AI-комментарий Claude), *История*.
- **Ночной обход** — сетка 6 палат; голосовой ввод: врач диктует поток («Палата 5, Иванов, пульс 78…»), AI разбивает по палатам/пациентам, извлекает витальные и статус.
- **Мониторинг ОРИТ** — карточки критических пациентов (ЧСС/АД/SpO₂/темп/ЧДД), цветовые статусы, «Вызвать врача»; ОРИТ + пост-реанимация. Пока статичные данные (нужен WebSocket/polling).
- **История** — группировка Сегодня/Вчера/Ранее, фильтры.
- **Настройки** — 5 табов: Профиль / Уведомления / Язык / Тема / О системе.
- **Админ** (`/admin`, `admin.html`) — одобрение/отклонение заявок врачей, i18n RU/TJ/EN.

**Ключевые фичи (в `app.js`):**
- **SOAP-генерация** (Claude Sonnet): S/O/A/P из транскрипта.
- **AI-рекомендации** — диффдиагностика с кодами **МКБ-10** и вероятностями, рекомендации обследований, предупреждения о конфликтах лекарств (клик → добавить в SOAP).
- **Evidence Link** — каждый элемент SOAP связан с моментом в транскрипте (клик по фразе → подсветка SOAP). Прослеживаемость/юр-защита.
- **Lab Connect QR** — врач выбирает анализы (**6 групп, ~38 тестов**: Клинические/Биохимия/Витамины/Инфекции/Гормоны/Инструментальные) → QR-направление → лаборант сканирует на портале `/lab` → вводит/загружает результаты (PDF/фото/DICOM) → результаты в карточке + AI-комментарий.
- **Avris Score** — AI-автооценка состояния пациента (0–100).
- **Ускорители:** dot-phrases (`..` → быстрые фразы), горячие клавиши (Ctrl+R запись, Ctrl+S сохранить, Ctrl+K поиск), Focus Mode, авто-сохранение черновика SOAP.
- **Экспорт PDF** (reportlab, кириллица), памятка пациенту, форма согласия.
- **Demo Mode** — при недоступности бэкенда фронт работает офлайн (typewriter-STT, мок-SOAP, in-memory CRUD; оранжевый бейдж `DEMO`).

**Карточка пациента (модалка):** возраст/пол/рост/вес/BMI/группа крови, диагнозы, анамнез, аллергии, назначения, Avris Score ring, sparkline витальных за 7 дней.

## 5. Технологический стек

**AI-ядро:** OpenAI **Whisper** (STT RU/TJ/EN) · Anthropic **Claude Sonnet** (SOAP, комментарии к анализам, инсайты). Выбор стека фиксирован.

**Backend** (`backend/`): **FastAPI** (Python, async) · SQLAlchemy · Pydantic v2 · python-jose (JWT) · passlib+bcrypt · python-multipart · reportlab · Resend · slowapi (rate-limit). БД: **SQLite** (`backend/avris.db`, dev) → PostgreSQL (prod-цель). Миграции: **Alembic**.

**Frontend:** чистый **HTML/CSS/JS без фреймворков/бандлера**. Темы dark/light/system, полная локализация RU/TJ/EN, адаптив 480px→десктоп, PWA/service worker.

## 7. Архитектура бэкенда (FastAPI)

- **Auth:** register → email-verify (Resend, 6-значный OTP) → login (JWT 7д) → профиль (13 полей) → аватар (canvas→base64 в БД). OTP/OAuth-state — в таблице **`auth_codes`** (alembic 0002). OAuth Google/Mail.ru рабочие.
- **Ревокация refresh-токенов** — таблица `refresh_tokens` (alembic 0004), `jti` в JWT, ротация убивает старый токен, `POST /api/auth/logout`, reset-password отзывает все сессии.
- **Audit-log** — таблица `audit_log` (alembic 0003, PHI-free мета) на мутациях patients/consultations/lab_orders/night_rounds/login/approve/reject/resets.
- **5 ресурсных модулей:** Patients · Consultations · Lab Orders · Night Rounds · STT/LLM-прокси.
- **Доступ:** все эндпоинты doctor-scoped (404/403 на чужие данные). Публичный портал лаборатории (`/by-token/...`, `PUT /results`) — **намеренно без авторизации** (для лаборантов).
- **ICD-10 валидация** LLM-кодов; email retry+escaping; пагинация `limit/offset` + `X-Total-Count`.
- **PWA:** `manifest.json`, `sw.js` (`/api` — network-only!, офлайн = Demo Mode, иконки `assets/icons/`). **При деплое бампать `SW_VERSION` в sw.js вместе с `?v=` ассетов.**
- **Waitlist:** `POST /api/waitlist` (honeypot `website`, slowapi 5/min, идемпотентный дедуп), `GET /api/waitlist/export` за `ADMIN_RESET_KEY`, модель `WaitlistEntry` (email/role/lang). Флаг **`WAITLIST_LIVE`** включает/выключает лендинг без деплоя.
- **PDF:** reportlab, авто-подбор кириллических TTF.
- **Ключи:** STT/LLM-эндпоинты возвращают **503 без `OPENAI_API_KEY` + `ANTHROPIC_API_KEY`** (в проде ключи заданы).
- **CI:** `tests.yml` — **58 pytest** на каждый пуш/PR; Security Check (bandit, `# nosec` для намеренного `0.0.0.0` в Railway-контейнере).

## 9. Локализация (i18n)

Три языка: **RU** (default) / **TJ** (тоҷикӣ) / **EN**. **~200 ключей** в объекте `TR`.
Атрибуты: `data-i18n` (textContent), `data-phk` (placeholder), `data-i18n-o` (option), `data-i18n-val` (input value), `data-i18n-title` (title).
`applyLang()` проходит по атрибутам и перерисовывает динамические экраны; EN-варианты данных пациентов выбираются в render по `lang==="en"`.
Локализованные структуры: `EV_TEMPLATES`/`EV_SOAP` (Evidence Link), `TR_LINES` (typewriter), `LAB_GROUPS` (38 анализов), `recBadgeMap`.
**Любые новые строки — только через TR-ключи (RU/TJ/EN).**

## 16. Известные пробелы (что не готово для продакшена)

- **Бэкенд:** SQLite (нужен PostgreSQL для масштаба); OTP/rate-limit **в памяти** → ломается при multi-instance (нужен Redis); аватары и лаб-файлы **base64/BLOB в БД** → нужен S3; нет бэкапов; Continuous Learning Pipeline — таблица есть, но S3/PHI-чистка/ночное обучение не реализованы.
- **Фронтенд:** нет реального стриминга Whisper (STT/LLM возвращают 503 без ключей); ОРИТ — статичные данные (нужен **WebSocket/polling**); `app.js` — монолит без сборки; нет unit-тестов (только smoke).
- **Бизнес/фандрейзинг:** нет финмодели (LTV/CAC/прогнозы); нет regulatory/compliance roadmap (медсофт в TJ/RU!); Investor Materials с пробелами; нет traction-данных, GTM-плана, cap table, клинической валидации.

- Тесты: E2E **playwright** (`npx playwright test`), API **pytest** (`pytest tests/`), мониторинг **pm2**.
